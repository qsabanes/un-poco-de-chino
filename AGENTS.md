# Content organization

- Class sessions define the learning order. Book units and page order never define or reorder sessions.
- Treat the book as supporting reference: map relevant pages to an existing session by topic, even across book units.
- Keep session PDFs, book support, and optional extensions distinguishable. Do not mark book-only words as studied in class or activate their decks by default.
- Preserve existing exercise IDs, flashcard IDs, and personal progress when adding material.
- Keep source PDFs local and out of this public repository. Publish original study notes and practice with source page references.
